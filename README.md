# Occlucrawlee

A Crawlee Web Spider for Horg.com, collects information on known Occlupanids.

## Commands

- `nix build`
  - Creates build enviroment and runs `npm build`
- `nix fmt`
  - Formats the project
- `nix develop`
  - Creates a development enviroment and drops you in a shell
- `nix run`
  - `nix build`s the project and runs it
